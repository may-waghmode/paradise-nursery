# Paradise Nursery Shopping Application

A responsive React and Redux Toolkit shopping cart for an online houseplant shop.

## Features
- Landing page with Paradise Nursery branding and Get Started button
- About Us company information
- Three plant categories with six plants each
- Product images, names, descriptions, and prices
- Redux Toolkit cart with addItem, removeItem, and updateQuantity reducers
- Disabled Add to Cart button after a product is added
- Dynamic cart item count, quantity controls, item deletion, and calculated totals
- Home, Plants, and Cart navigation
- Checkout Coming Soon message

## Run locally
```bash
npm install
npm run dev
```

## Technology
React, Vite, React Router, Redux Toolkit, React Redux.
